How to Read Boxplot

กราฟ Boxplot แสดงการกระจายตัวของ PM2.5 / PM10 ในแต่ละประเภทหุบเมือง (Canyon Type) รายสัปดาห์ ใช้เปรียบเทียบว่า Type ใดมีมลพิษสูง-ต่ำ และกระจายมากน้อยแค่ไหน

ส่วนประกอบของ Box
เส้นกลาง Median (Q2) — ค่ากลาง 50% ต่ำกว่า / 50% สูงกว่า
กล่อง IQR (Q1–Q3) — ช่วงกลาง 50% ของข้อมูล กล่องกว้าง = กระจายมาก
หนวด Whisker — Min / Max ที่ไม่ใช่ outlier ยิ่งยาว ค่าสุดขั้วยิ่งมาก
3 มุมมองกราฟ

Overview รวมทุก Type ในกราฟเดียว เปรียบเทียบภาพรวม 22 สัปดาห์พร้อมกัน
Weekly เลือกสัปดาห์ที่สนใจ แล้วดูทุก Canyon Type ในสัปดาห์นั้นเปรียบเทียบกัน
Canyon Types
Non canyon ถนนโล่ง H/W ≈ 0 อากาศถ่ายเทดี มลพิษสะสมน้อยที่สุด
On viaduct บนทางยกระดับ โล่งกว่าปกติ
Under viaduct ใต้ทางยกระดับ ร่มและอากาศถ่ายเทลดลง
0<H/W<1 อาคารเตี้ย แสงแดดและอากาศยังดี
1<H/W<2 ความหนาแน่นปานกลาง เริ่มสะสมมลพิษ
2<H/W<4 หุบลึก อากาศถ่ายเทน้อย มลพิษสูง
H/W>4 หุบลึกมาก อากาศแทบไม่ถ่ายเท ความเสี่ยงสูงสุด
