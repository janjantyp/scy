How to Read Tukey HSD

กราฟ Tukey HSD แสดง p-value จากการเปรียบเทียบแบบ Pairwise ระหว่างทุกคู่ของ Canyon Type ในแต่ละสัปดาห์ — ใช้ดูว่าคู่ไหนมีค่ามลพิษแตกต่างกันอย่างมีนัยสำคัญทางสถิติ

การอ่านค่า p-value
p < 0.05 มีนัยสำคัญ — คู่นี้มีค่ามลพิษต่างกันจริง ไม่ใช่ความบังเอิญ
p ≈ 0.05 Borderline — อยู่แนวขอบ ควรตีความด้วยความระมัดระวัง
p > 0.05 ไม่มีนัยสำคัญ — คู่นี้ค่ามลพิษไม่ต่างกัน หรือต่างได้จากความบังเอิญ
สเกลสี
0.0 (Sig.) 0.5 1.0 (Non-sig.)
วิธีอ่าน Heatmap
แกน X / Y แต่ละแกนคือ Canyon Type — ช่องตัดกันแสดง p-value ของคู่นั้น
สมมาตร Matrix มีความสมมาตร — ช่องบนขวา = ช่องล่างซ้าย ค่าเหมือนกันทุกคู่
Hover ช่อง วาง cursor บนช่องใดก็ได้เพื่อดู p-value และผลการทดสอบแบบละเอียด
Canyon Types
Non canyon ถนนโล่ง H/W ≈ 0 อากาศถ่ายเทดี มลพิษสะสมน้อยที่สุด
On viaduct บนทางยกระดับ โล่งกว่าปกติ
Under viaduct ใต้ทางยกระดับ ร่มและอากาศถ่ายเทลดลง
0<H/W<1 อาคารเตี้ย แสงแดดและอากาศยังดี
1<H/W<2 ความหนาแน่นปานกลาง เริ่มสะสมมลพิษ
2<H/W<4 หุบลึก อากาศถ่ายเทน้อย มลพิษสูง
H/W>4 หุบลึกมาก อากาศแทบไม่ถ่ายเท ความเสี่ยงสูงสุด
Sig. Pairs avg.
% Sig. เปอร์เซ็นต์ของคู่ทั้งหมดที่มี p < 0.05 เฉลี่ยจากสัปดาห์ที่แสดงในช่วงนั้น — ยิ่งสูงยิ่งมีหลายคู่ที่แตกต่างกัน
